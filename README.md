# 🎓 University Management System

A Desktop Application designed to handle various administrative and academic tasks in a university environment. Built using **Java**, **Java Swing (GUI)**, and **MySQL Database**.

---

## 🚀 Features

- 👨‍🎓 **Student Management:** Add, update, view, and manage student details.
- 👨‍🏫 **Faculty Management:** Maintain professor and department details.
- 📝 **Examination & Marks:** Enter, update, and display student grades and examination results.
- 🗓️ **Leave Management:** Handle leave applications for both students and teachers.
- 💳 **Fee Structure:** Manage and track student fee payments.

---

## 🛠️ Tech Stack & Tools

- **Language:** Java (JDK 8+)
- **User Interface:** Java Swing / AWT
- **Database:** MySQL
- **Libraries Used:** 
  - `mysql-connector-java` (Database connectivity)
  - `rs2xml` (Populating JTable with ResultSets)
  - `jcalendar` (Date chooser UI components)
- **IDE:** IntelliJ IDEA
